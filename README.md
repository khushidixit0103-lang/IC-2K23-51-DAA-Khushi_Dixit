## 📌 Repository Overview

This repository contains the complete practical curriculum, implementations, performance measurements, complexity analyses, and documentation for the **Design and Analysis of Algorithms Lab (IC-709 B)** as prescribed by the university syllabus.

All algorithm implementations are developed in pure Python adhering to undergraduate pedagogical standards, with modular functions, clear algorithmic steps, robust input validation, and empirical performance analysis using Matplotlib and NumPy.

## 📑 Syllabus & Unit Mapping

| Unit | Title | Course Outcome | Core Mandatory Experiments |
|---|---|---|---|
| **Unit 1** | Introduction to Algorithms & Performance Analysis | CO1 | Basic array operations, Iterative Binary Search, Recursive Binary Search, Best/Average/Worst-case analysis, Empirical time measurement, Performance plots |
| **Unit 2** | Divide and Conquer | CO1 | Binary Search (D&C), Maximum & Minimum (D&C), Merge Sort, Quick Sort, Heap Sort, Strassen's Matrix Multiplication, Empirical runtime comparisons |
| **Unit 3** | Greedy Method | CO2 | Fractional Knapsack, Job Sequencing with Deadlines, Prim's Minimum Spanning Tree, Kruskal's Minimum Spanning Tree, Spanning tree comparisons |
| **Unit 4** | Dynamic Programming | CO3 | Fibonacci (Recursion vs Memoization), 0/1 Knapsack (DP), Multistage Graph, All-Pairs Shortest Path (Floyd-Warshall), Single-Source Shortest Path, Travelling Salesperson Problem (DP) |
| **Unit 5** | Basic Traversal & Search Techniques | CO6 | Binary Tree Creation & Traversals (Preorder, Inorder, Postorder - Recursive & Iterative), Graph Representations (Matrix & List), BFS, DFS (Recursive & Iterative) |
| **Unit 6** | Backtracking | CO4 | General Backtracking Framework, 4-Queens, 8-Queens, N-Queens Problem, Sum of Subsets Problem, Search-space state count analysis |
| **Unit 7** | NP-Hard, NP-Complete & Advanced Optimization | CO5, CO7 | Exhaustive Search, 0/1 Knapsack using Branch & Bound, TSP using Branch & Bound, DP vs Branch & Bound Comparisons |
